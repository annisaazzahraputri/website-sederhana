# LaundryKu — Tugas 4 Frontend Skeleton

Aplikasi laundry praktis untuk kebutuhan sehari-hari. Dibangun dengan **Tailwind CSS** sebagai single-page app.

## Halaman
- **#home** → Dashboard dengan grid layout (hero + card layanan)
- **#layanan** → Tabel daftar harga & estimasi
- **#form** → Form tambah pesanan
- Navbar responsif dengan hamburger menu di mobile

## Alasan Memilih Tailwind CSS
- Utility-first, cepat untuk membuat tampilan responsif
- Fleksibel untuk desain modern & clean sesuai karakter LaundryKu
- Tidak perlu banyak override CSS seperti Bootstrap
- Cocok untuk proyek fullstack yang akan berkembang hingga pekan ke-14
